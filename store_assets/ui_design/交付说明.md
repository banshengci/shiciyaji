## 二、设计系统落地（对应需求 2.x）

- **色彩**：9 色全部按规范取值（黛蓝 / 朱砂红 / 宣纸白 / 墨黑 / 青灰 / 淡黄 / 苍青 / 石黄 / 松绿），在 `:root` CSS 变量中集中管理。
- **字体**：全站 serif（Noto Serif SC 衬线，含 brush 书法字体用于印章/标题），标题 20sp 加粗、正文 16sp 行高 1.8、次要文字 14sp 青灰。
- **圆角**：卡片 12px / 按钮 10px / 输入框 10px。
- **间距**：左右边距 16px / 卡片内边距 16px / 列表项间距 8px / 区块间距 24px。
- **暗色模式**：新增语义化 CSS 变量体系（`--bg / --surface / --surface-2 / --text / --text-2 / --primary / --accent / --border`），`body.dark` 切换为深墨蓝背景（`#111A24`）、黛蓝反色标题（`#B7C7D6`）、提亮朱砂红（`#E23B3B`），所有卡片、按钮、Toast、侧栏同步适配。

## 四、如何预览

直接双击 `index.html` 用浏览器（Chrome / Edge）打开：
- 点击底部 5 个标签切换页面；
- 诗词库点「网格」图标切换视图、点朝代胶囊筛选；
- 点任意诗词进入详情，可收藏（心跳）、点「学习」变朱砂红「已学习」；
- 搜索框输入「李白 / 春 / 思」等实时高亮；
- 我的 → 学习统计 / 成就墙；
- 我的 → 打开/关闭「暗色模式」，刷新后保持。

> 建议浏览器窗口 ≥ 900px 宽，以便左侧说明面板与手机原型并排显示。

## 五、三端图标包

所有图标已按 **Android / iOS / Windows** 规范切片并输出到 `icons/` 目录：

- **Android**：`res/mipmap-*` 5 组密度（48/72/96/144/192），含圆角版；`mipmap-anydpi-v26/` 自适应图标 XML + 前景/背景 PNG；`play_store/` 512 商店高清图；附带 `icon_fg.svg` / `icon_bg.svg` / `icon_launcher.svg`。
- **iOS**：`AppIcon.appiconset/` 含 13 张 PNG（20~1024）+ 正确的 `Contents.json`（含 iPhone / iPad / Marketing 配置）。
- **Windows**：UWP 标准目标尺寸 PNG（Square44~310、Wide310x150、StoreLogo、BadgeLogo、SplashScreen）+ 多尺寸 `appicon.ico`（16/32/48/256）。

每个平台子目录都有独立 `README.md`，包含清单、集成步骤与 `Package.appxmanifest` / `AndroidManifest.xml` 引用示例。

如需重出或改色，运行：

```bash
python gen_icons.py
```

## 六、关于矢量图标栅格化（备用）

`assets/icon_launcher.svg` 仍为矢量源文件。若后续需要手动导出 PNG，可用：

```bash
npx -y resvg-cli assets/icon_launcher.svg icon_launcher.png -w 512 -h 512
```
