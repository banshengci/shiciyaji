# 诗词雅集 · 全平台 UI/UX 设计需求

## 一、产品定位

古诗词学习与欣赏的全平台应用（Android / iOS / Windows），新中式（Neo-Chinese）设计风格。
目标用户：学生、诗词爱好者，主要使用场景为碎片化阅读和学习。

---

## 二、设计规范

### 2.1 色彩体系

| 名称 | 色值 | 用途 |
|------|------|------|
| 黛蓝 | #1A2A3A | 主色调：标题、导航栏文字、按钮 |
| 朱砂红 | #C41A1A | 强调色：选中态、收藏心形、学习进度 |
| 宣纸白 | #F5F0E8 | 背景色 |
| 墨黑 | #222222 | 正文文字 |
| 青灰 | #6B7280 | 次要文字（作者、朝代、时间） |
| 淡黄 | #FDF6E3 | 卡片背景、搜索框背景 |
| 苍青 | #4F6F8F | 图表辅助色 |
| 石黄 | #D9A534 | 图表辅助色 |
| 松绿 | #5B7A4A | 图表辅助色 |

### 2.2 字体

- **所有文字**：统一使用 serif（宋体/衬线字体）
- **标题**：20sp，加粗
- **正文**：16sp，行高 1.8
- **次要文字**：14sp，青灰色 #6B7280

### 2.3 圆角

- 卡片：12px
- 按钮：10px
- 输入框：10px

### 2.4 间距规范

- 页面左右边距：16px
- 卡片内边距：16px
- 列表项间距：8px
- 区块间距：24px

## 三、需要设计的页面

### 3.1 底部导航栏（5个标签）

| 标签 | 图标 | 选中色 | 未选中色 |
|------|------|--------|----------|
| 首页 | 房子/Home | 朱砂红 #C41A1A | 青灰 #6B7280 |
| 诗词库 | 书本/BookOpen | 朱砂红 | 青灰 |
| 搜索 | 放大镜/Search | 朱砂红 | 青灰 |
| 收藏 | 心形/Heart | 朱砂红 | 青灰 |
| 我的 | 用户/User | 朱砂红 | 青灰 |

**底部导航栏背景**：宣纸白 #F5F0E8，顶部有 0.5px 分割线

### 3.2 首页

**顶部**：
- 大标题「诗词雅集」居中，serif 字体，黛蓝色

**每日一诗卡片**：
- 浅黄色背景 #FDF6E3
- 卡片圆角 12px
- 左上角标签「每日一诗」朱砂红小字
- 诗名（大字加粗）+ 朝代·作者（小字青灰）
- 诗句预览 2-3 行
- 底部右下角「开始学习」按钮

**学习进度区**：
- 横向排列 3 个统计数字卡片
- 「已学 XX 首」「收藏 XX 首」「连续 X 天」
- 数字用大号 serif 加粗，下方小字说明

**快捷入口**：
- 2×2 网格图标按钮
- 学习计划 / 今日复习 / 阅读历史 / 学习笔记
- 每个入口：图标 + 文字，浅色背景圆角卡片

### 3.3 诗词库页面

**顶部**：
- 标题「诗词库」居中
- 右上角两个图标：网格视图/列表视图切换、筛选（漏斗图标）

**筛选栏（可展开）**：
- 横向滚动标签：全部 / 唐 / 宋 / 元 / 明 / 清 / ...
- 标签样式：圆角胶囊，选中为黛蓝底白字，未选为淡黄底黛蓝字

**诗词列表（列表视图）**：
- 左侧：诗名（serif 加粗 16sp）+ 朝代·作者（青灰 14sp）
- 右侧：体裁标签（小圆角胶囊，如「唐诗」「宋词」）
- 底部：第一句诗预览（青灰 14sp，最多 1 行，溢出省略）
- 列表项之间无分割线，靠间距区分

**诗词列表（网格视图）**：
- 2 列网格
- 每张卡片：浅黄背景，居中诗名，下方朝代·作者

### 3.4 诗词详情页

**顶部导航**：
- 左箭头返回
- 居中标题为诗词名
- 右侧：收藏心形图标 + 更多（三点菜单）

**正文区**：
- 诗名（大号 serif 加粗居中）
- 「朝代 · 作者」（青灰色居中）
- 诗句正文（serif 16sp，行高 2.0，居中排列）
- 每句一行，对仗工整

**底部操作栏**：
- 固定在底部，宣纸白背景
- 4 个图标按钮横排：
  - 学习（书本图标）
  - 笔记（铅笔图标）
  - 分享（分享图标）
  - 朗读（播放图标）
- 点击「学习」后变为「已学习」，朱砂红色

**展开区（向上滑动可看）**：
- 注释 / 翻译 / 赏析 / 背景
- 每个区块有小标题 + 内容
- 折叠/展开切换

### 3.5 搜索页面

**搜索框**：
- 顶部固定，圆角搜索框
- 左侧放大镜图标
- placeholder: "搜索诗词名、作者、内容..."
- 搜索框背景：淡黄色 #FDF6E3

**搜索结果**：
- 与诗词库列表样式一致
- 关键词高亮显示（朱砂红色加粗）

**空状态**：
- 居中灰色放大镜图标
- 文字「输入关键词搜索诗词」

### 3.6 收藏页面

**顶部**：
- 标题「收藏」
- 右上角「管理」按钮

**收藏夹列表**：
- 每个收藏夹一行：名称 + 诗词数量
- 支持创建新收藏夹、重命名、删除
- 默认收藏夹不可删除

**收藏夹内诗词**：
- 与诗词库列表一致

### 3.7 我的页面

**个人信息区**：
- 头像（默认水墨风格圆形头像）
- 昵称
- 学习天数

**功能列表**：
- 学习记录
- 我的笔记
- 学习统计
- 成就墙
- 设置
- 关于

每个入口：左侧图标 + 文字，右侧箭头

### 3.8 学习统计页

**热力图**：
- 类似 GitHub contributions 的方格热力图
- 颜色深浅表示学习量
- 朱砂红色系

**数据卡片**：
- 总学习诗词数
- 已掌握数
- 今日待复习数
- 连续学习天数

**图表**：
- 朝代分布饼图
- 作者分布柱状图（前 10 名）

### 3.9 成就墙

**成就卡片网格**：
- 3 列网格
- 已解锁：彩色图标 + 名称
- 未解锁：灰色图标 + 名称 + "???"

## 四、应用图标设计

### 4.1 启动画面（Splash Screen）

- 背景：宣纸白 #F5F0E8
- 居中：应用图标
- 图标下方：「诗词雅集」四个大字（serif 黛蓝色）
- 底部：一行小字「品读千年文脉，传承诗词之美」

### 4.2 应用图标（Launcher Icon）

- **形状**：圆角方形（Android Adaptive Icon）
- **背景**：黛蓝 #1A2A3A
- **前景**：
  - 一个展开的古籍/书卷图形
  - 或一个毛笔书法「诗」字
  - 颜色：宣纸白 #F5F0E8
- **风格**：简约、现代感的中式元素，不要过于复杂
- **需要提供**：
  - 512×512px 高清版（用于应用商店）
  - Adaptive Icon 前景层（108×108dp）
  - Adaptive Icon 背景层（108×10dp，纯色即可）

## 五、交互规范

### 5.1 手势

- **左滑**：诗词详情页返回
- **下拉**：诗词库刷新
- **长按**：诗词卡片弹出快捷操作（收藏、加入学习计划）

### 5.2 动画

- 页面切换：从右向左滑入
- 收藏心形：点击时有心跳放大动画
- 加载中：水墨风格 loading 动画（可选）
- 学习完成：撒花/盖章动画（可选）

### 5.3 Toast / 提示

- 收藏成功：底部 Toast「已添加到收藏」
- 取消收藏：底部 Toast「已取消收藏」
- 学习完成：底部 Toast「学习完成 +1」
