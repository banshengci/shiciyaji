### 本次踩坑（重要）
1. **构建被沙箱拦截**：`[sandbox] 命令被沙箱拦截 ... build/path_provider_android/...`
   → 报 `error: failed to create archive.`，并伴随误导性的
   "requires a newer version of the Kotlin Gradle plugin" 提示。
   **真因是沙箱，不是 Kotlin 版本**。用 `dangerouslyDisableSandbox: true`
   单独重跑即成功（97s）。
2. **Git Bash 里 `taskkill //F //IM` 参数解析失败**：`错误: 无效参数/选项 - '//F'`。
   清理 Java 进程别用这种转义写法；本项目直接 `./gradlew --stop` 即可，
   或改用 PowerShell 的 `Stop-Process`。
3. **`flutter pub get` 偶发异常输出**（executable.dart 堆栈），重跑即恢复；
   判断成功与否看结尾 "Got dependencies!"，不要被中途堆栈吓到。

### 备注
- 若需更小体积：`flutter build apk --split-per-abi` 或
  `--target-platform android-arm64`（仅 arm64 设备可装，约 25 MB）。
- 未启用混淆/资源压缩：Flutter + JNI/反射场景有崩溃风险，自用离线 App 收益小。

### 本次修的两个 CI 必炸点
1. **workflow IPA 路径不一致**：`zip -qry ../../shici_yaji.ipa`（输出 build/ 下）
   但 `upload-artifact` 的 path 写 `build/ios/shici_yaji.ipa` → 上传必失败。
   改用 `$GITHUB_WORKSPACE/build/ios/shici_yaji.ipa` 绝对路径，并加校验步骤。
2. **Podfile 缺 Xcode 15+ 兼容**：macos-14 runner（Xcode 15/16）会报
   `DT_TOOLCHAIN_DIR cannot be used to evaluate LIBRARY_SEARCH_PATHS`。
   post_install 里补 `DT_TOOLCHAIN_DIR → TOOLCHAIN_DIR` 替换（官方推荐写法）。
   另加 flutter doctor -v 自检、pod install --repo-update、timeout 60。
