**可复用的技术要点**
- 竖排文字实现：单个 text 节点用 `\n` 分隔每个汉字 + 固定窄宽度 + `textAlignHorizontal:"CENTER"`，即可渲染成竖排一列（无需竖排属性）。多列用 horizontal frame 承载，`primaryAxisAlignItems:"MAX"` 实现右起。
- 诗句换行必须**手动按句断行**（`京口瓜洲一水间，\n钟山只隔数重山。`），交给自动换行会把句子拦腰切断。
- 朝代分类色：唐 #C41A1A / 宋 #1A2A3A / 元 #4A6754 / 明 #B07A3C / 清 #6B7280（在原四色体系上按功能扩展）。
- `wrap` 网格里子项写 `height:"hug_contents"` 时，新增子节点后容器高度**不会立即重算**，`capture_layout` 会报假溢出；显式给单元格一个固定高度（710 = 40+14+600+14+42）即可彻底消除。
- 横向 layout 里若某个子节点写 `height:"fill_container"`（如左侧色带），父容器又是 `hug_contents`，父高度会被**算漏**（内容被压扁、下方留大片空白）。解法：给父容器一个显式高度，并让内容 `primaryAxisAlignItems:"CENTER"` 垂直居中。
- 画布上的字号是「展示板字号」（为了在 2040 宽板上看清而放大），**不等于移动端实尺**。做「落地对照」区时按 `实尺 × 1.6` 等比放大，并按 Flutter 真实行高重算卡片高度，避免设计稿与代码对不上。

## 分享卡落成：04 名句摘录接入每日一诗与分享页

**背景**：8 款样式里 04（名句 · 大字摘录）是唯一能直接提升分享转化的一款，且不依赖列表页改造。本轮把它落成代码，接到首页「今日推荐」与分享卡页。

**新增** `lib/presentation/widgets/poem_share_cards.dart`
- `enum PoemShareStyle { quote, classic }` + `PoemShareStyleStore`（SharedPreferences，key `poem_share_style`，默认 quote）。**分享偏好与列表偏好是两个 key**：列表样式是「怎么浏览」，分享样式是「怎么把一首诗带走」。
- `poemQuoteOf(poem)` → `PoemQuote{primary, secondary, source, curated}`，三级策略：
  1. 人工名句表 `_curatedQuotes`（32 条，只收「记忆点不在末联」的篇目，其余交给启发式）；
  2. **表内句子必须在正文里真实存在**（`_contained`），否则弃用 —— 这条校验让同题异篇自动走各自正解：两首《凉州词》只有正文匹配上的用表，另一首回落启发式，结果恰好也对；
  3. 末联启发式（绝句与词的记忆点绝大多数落在「转合」两句）。
  - 断句 `_splitQuote`：显式分界符 `｜` > 最后一个「，」（两半各 ≤12 字）> 整联作大字句。`_trimTail` 去掉句尾 `。，、；` 但**保留 `？`**——「问君能有几多愁？」的 ？ 是句意本身。
  - 繁简：人工表存简体，在 `_splitQuote` 里统一过一遍 `S2TConverter.apply`，否则繁体偏好下与正文对不上。
- `PoemShareCard` 分发 quote（04：黛蓝渐变 + 32px 名句 + 20px 对句 + 出处 + 描边方印）/ classic（由原 `PoemCardWidget` 迁移，行为不变）。

**关键设计决定：分享卡配色写死，不读明暗令牌。** 分享卡最终是一张导出的 PNG，跟随深色模式会让同一首诗白天与夜里分享出两种图 —— 那不是自适应，是不可复现。这是全站唯一刻意不用 `ShiciColors` 的地方。

**04 卡字号按宽度反解**：`usable ÷ 字数` 夹在 [24, 32]。名句必须一行压住版面，折行的「大字句」等于没有大字；5–7 字短句在绝大多数机型上吃满 32，长词句才逐级收小。

## 深色模式对照版 · 朝代色与「压在品牌色上的前景」

**背景**：8 款卡片样式与 02/03/07/04 落地后，深色模式从未单独核过色。
本轮把 `ShiciColors.dark` 整个过了一遍对比度，发现的问题比预期严重。

**核心发现（深色下照搬浅色值 = 系统性问题）**
| 朝代色 | 深色旧值 | 在卡面 #1C2129 上 | 判定 |
|---|---|---|---|
| 宋 · 黛蓝 | `#2E4257` | 1.57:1 | 完全糊掉 |
| 元 · 松绿 | `#4A6B52` | 2.71:1 | 色带/徽记读不出 |
| 明 · 赭石 | `#A8663B` | 3.56:1 | 不达 AA |
| 唐 · 朱砂 | `#D94A3D` | 3.85:1 | 不达 AA |
| 清 · 藤黄 | `#C9992E` | 6.22:1 | 深色 OK、浅色才是问题（2.43:1）|

**定值方法（可复用）**：高彩度色一提亮就褪成粉，所以不能只按明度反解。
做法是**锁死原色相与原彩度，只扫明度**，一路抬到四种真实用法同时达标：
① 徽记字压在自身色调底纹上（≥4.5）② 6px 色带压卡面（≥3）③ 实心胶囊上的前景（≥4.5）
④ 页面底图标/强调字（≥4.5）。结果是一组「旧绢上的矿物色」：
朱砂→珊瑚 `#EB6767` / 黛蓝→月白 `#6F96BE` / 松绿→苔绿 `#719D7B` /
赭石→陶土 `#C48358` / 藤黄→琥珀 `#B78B2A`（均 5.1~5.2:1）。
⚠️ 曾试过「最大化彩度」求解，得到 `#03FC3D` `#FC6703` 这类屏幕霓虹色，与新中式完全不搭，已弃用。

**顺带发现的浅色缺陷（已一并修）**
- 清 · 藤黄 `#C9992E` 在纸白上只有 **2.43:1** —— 清代色带基本看不见 → `#7E601B`（5.50）
- 明 · 赭石 `#A8663B` 4.25:1 → `#925933`（5.31）
- 字-三 `#A8A396` 2.36:1 → `#8D8776`（3.35，按弱提示层 3.3 门槛，不按正文 4.5，否则与字-次塌成一级）

**结构性缺陷：「压在品牌色上的前景」整条链路**
浅色下用 `c.silk` / `c.paper` 当实色块上的前景「碰巧」是对的；深色下这两个令牌会翻转，
于是变成墨字压墨底。新增两个语义令牌区分两种场景：
- `onAccent` 压**品牌实色块**（品牌色深色下变亮 → 前景翻转）：浅 `#FAF7F2` / 深 `#12171C`
- `onDeep` 压**固定深色块**（底色不随模式变 → 前景也不变）：两模式同 `#F5F0E8`
- `deepFrom/deepTo` 深块渐变：浅 `#1A293B→#2E4257`（＝分享卡）/ 深 `#23334D→#354962`
  （旧值落墨底上可分辨度只有 1.222，抬到 1.418）

**🔴 本轮最重要的发现：`ShiciContrast.luminance` 量纲 BUG**
`Color.red/green/blue` 是 **0~255 的整数**（0~1 的访问器是 `.r/.g/.b`），原实现又乘了一次 255：

```dart
_channel(c.red.toDouble()) // ✅ 21.00
```
**数值全错、但大小关系仍在** —— 于是 `design_system_test.dart` 那批「≥ 4.5:1」的守卫**全都安静地通过了**，238 项测试无一能发现。是靠像素复核对账一份独立 Python 参考值才翻出来的。

**加固**：新建 `test/contrast_reference_test.dart`（13 项），把参考值逐项钉死 ——

**一句话**：守卫证明「关系对」，对账证明「数值对」，两者缺一不可。

## 把「对账 + 像素复核」推到三页面 —— 牵出一个 67 处的全局缺陷

**背景**：stats / review / settings 三页只过了公式层守卫（`design_system_test` 的可读性断言），
没有独立实现的对账，也没有像素复核。本轮把上一节的方法推过去，结果先撞出一个更大的问题。

**🔴 核心发现：恒定浅色常量在深色下不跟随模式**
`lib/core/theme.dart` 里的历史兼容别名 —— `AppTheme.daiLan` / `zhuShaHong` / `songLv` /
`shiHuang` / `qingCang` / `tongSe` / `qingHui` / `yaBai` —— 都是 `static const`，
**值等于浅色令牌、与 `BuildContext` 无关**。深色下拿它画「字压底」等于墨字压墨底：
实测 `daiLan` 压深色卡面 `#1C2129` 只有 **1.11:1**，完全隐形。
全项目 **12 个页面 67 处**，公式层守卫一条都发现不了（它只校验令牌本身，不校验「谁在用」）。

**修复映射（恒定常量 → 语义令牌）**
| 旧别名 | 令牌 | 旧别名 | 令牌 |
|---|---|---|---|
| `daiLan` | `indigo` | `qingCang` | `cerulean` |

| `songLv` | `pine` | `qingHui` | `inkSoft` |
| `shiHuang` | `gamboge` | `yaBai` | `inkFaint` |
