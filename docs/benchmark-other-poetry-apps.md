## 一、我们的现状（已有，下列建议不重复）

每日一诗 · 诗库（朝代/体裁/主题） · 全文检索（标题/作者/正文 + 拼音全拼与首字母，按字/按句 + 高亮）·
收藏与收藏夹 · 学习计划（预置/自建/每日定量/今日任务） · 艾宾浩斯复习 · 打卡热力图与连续天数 ·
内容可信度标注 + 本地补写 · 逐句跟读（TTS + 单句循环） · 客观题自测（补全/接下句/猜作者） ·
学习月报（导出长图） · 笔记 · 离线包 1320 首 · TTS 朗读 · 明暗主题 + 全局字号四档 · 统计图表 ·
10 项成就 · 备份恢复（全量 JSON） · 一日一赏卡片流 · 抄写/练字 · 飞花令（单字令）+ 飞花段位 ·
名句日签 · 相关篇目 · 听写 · 作者年表 · 收藏/听诗连播 · 教材同步单元计划 · 节气节日专题 · 竖排阅读。

**判断原则**：只收「能离线落地、不引入账号/服务端/社区、不与内容诚信冲突」的项。
凡需联网、需服务端、需版权音频、或属 AI 生成内容的，一律进「不借」。

## 二、可借鉴清单（按优先级）

### P0 · 立刻可做（零/极小新依赖，体感强，多数能复用现有积木）

| # | 功能 | 谁在做 | 怎么做 | 我们能复用的积木 | 工作量 |
| --- | --- | --- | --- | --- | --- |
| 1 | **繁简一键切换** | 搜韵、诗一 | 设置内简/繁实时互转，检索也兼容繁体输入 | **已有 `assets/data/t2s_mapping.json`（3751 对映射）** | 极小 |
| 2 | **TTS 倍速 + 多音色 + 定时关闭/渐弱** | 古文岛、诗一、喜马拉雅 | 0.5–2.0 倍速、系统多音色、睡前「播完当前/15·30·60 分」后渐弱停止 | `tts_service.dart`（已有逐句朗读） | 小 |
| 3 | **平仄·韵脚标注层 + 韵部查询** | 搜韵（律诗校验）、诗词吾爱 | 读诗时可切换显示逐字平仄/韵脚/粘对，并查某字属平水韵·词林正韵及同韵部字 | `verse_splitter.dart`（按句切分）+ 自建平仄/韵书静态数据 | 小-中 |
| 4 | **默写 / 填空检测 + 易错字设空 + 错题本** | 古诗文全解、默写类 App | 隐藏关键词或整句遮挡后作答，即时批改、高亮错字、自动归入错题本 | **`quiz_generator.dart` + `recordRecall`（已有客观题与错题闭环）** | 小 |
| 5 | **连胜冻结 / 补签卡** | 多邻国（Streak Freeze）、墨墨背单词（补签） | 连续打卡断了可用「冻结」保住、或用补签卡补回 | `study_records` + 打卡热力图 | 极小 |

> 其中 #1（繁简）几乎零成本——映射表已在仓库里，只是没接出来。

## 三、明确不借（及理由）

| 不借 | 理由 |
| --- | --- |
| 联网实时对战 / 全服排行榜 / 社区 / UGC 创作 / 话题关注 | 需服务端；且内容安全审核是合规硬成本，与「离线、个人使用」定位冲突 |
| AI 智能体（与诗人对话）/ AI 生成插图 / AI 音色 | 需联网大模型；更与**内容诚信**原则直接冲突——我们连脚本生成的赏析都要标注，不能引入生成内容冒充精校 |
| 会员 / 内购 / 广告 / 文创电商 | 项目定位是自用与分享，不做变现 |
| 跨设备同步 / 账号体系 | 数据自主（本地 JSON 导出）是我们的优势，不应换回账号绑定 |
| 真人朗诵音频 / 在线曲库 | 版权问题 |
| 方言朗读 / 古人发音模拟 | 依赖系统 TTS 语音包，三端不一致，且准确性无法验证 |
| 几十种商业书体 | 字体授权不在个人项目范围 |
| AR 实景诗词 / 三维汉字演化 | 多为营销噱头、依赖联网，未见离线可行证据（未证实） |
| 看图猜诗 | 需本地图库，暂缓（飞花令已是趣味入口） |
| 跨设备家长监控 | 需账号云端；改为本机报告导出 |

## 四、我们的护城河（借鉴时别丢）

1. **真离线**——无网络依赖，断网/飞机上完整可用。
2. **数据自主**——全量 JSON 导出与合并恢复，含用户补写内容；换机不求人。
3. **内容诚信**——分级标注 + 本地补写，竞品无人做；这是最该保持的差异点。
4. **真间隔重复**——艾宾浩斯 + 客观题反馈，多数竞品只有「每日打卡」。
5. **三端同源**——Windows 桌面端功能完整（大屏读长词体验优于手机）。
6. **无账号 · 无广告 · 无内购**——打开即用。

## 五、建议的下一步（Top 5，按「性价比 × 复用度」）

| 顺序 | 做什么 | 为什么先做 |
| --- | --- | --- |
| 1 | **繁简一键切换** | 零新依赖（映射表已在仓库）、体感最直接、契合古籍阅读 |
| 2 | **TTS 倍速 / 多音色 / 定时关闭** | 系统 TTS 即可，直接增强已有「听诗」体验 |
| 3 | **平仄·韵脚标注层 + 韵部查询** | 数据小（平仄字典 + 韵书），直接服务「读懂与背诵」，竞品把它当核心卖点 |
| 4 | **默写/填空检测 + 错题本** | 复用已有客观题与错题闭环，补齐应试场景，家长/学生刚需 |
| 5 | **主动回忆卡片 + 每日回顾队列** | 把「收藏/笔记/名句」盘活成复习资产，比固定艾宾浩斯更进一步 |

> 前 4 项都可归入「一期」并行推进；第 5 项与复习调度改动相关，建议单独一批并配回归测试。
