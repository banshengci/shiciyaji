# 竞品功能对照：西窗烛 / 古诗岛·古文岛

> 信息来源：应用商店与官网的介绍文案、更新日志、用户评论（2026-09-16 查）。
> **没有反编译或抓包**，所以下面写的是「他们公开宣称有什么、怎么用」，
> 具体交互细节（动效、手势、信息层级）不在对照范围内。
> 「古诗词岛」在商店里对应两款：**古诗岛**（深圳市舞动乐趣）与**古文岛**（重庆典识古科技，
> 就是那个有桌面小组件和「考一考」的）。二者一并看，重点看功能更完整的**古文岛**。

## 一、他们的功能全景

| 模块 | 西窗烛 | 古诗岛 / 古文岛 |
| --- | --- | --- |
| 内容量 | 百万级文库 + 典籍（诗经 / 论语 / 山海经 / 四大名著…）+ 鉴赏辞典书籍 | 各朝代诗词 + 文言文（诗经 / 楚辞 / 史记），初高中必背 |
| 内容字段 | 注释 · 译文 · 赏析 | 原文 · 译文 · 注释 · 赏析 · **拼音** · 朗读 |
| 检索 | 朝代 / 作者 / 作品；精选分类十余维（选集·主题·写景·节日·节气·词牌·时令·用典·地理·名山·城市·时间·花卉·课本） | 按**字**、按**句**搜索，**关键词高亮** |
| 每日机制 | **一日一赏**（每日诗词卡片，右滑收藏） | 每日推送 |
| 计划 | 学习计划：把「经典 / 分类 / 诗单」设为计划，每天打卡 | **背诵计划**（可自定） |
| 练习 | 诗词游戏：飞花令 · 诗词接龙 · 看图猜诗 · 诗词测试；诗词抄写 / **练字模式**（几十种书体临摹） | **诗词填空**（给上句填下句）· 诗词背诵 · **考一考** |

| 工具 | **桌面小组件**（自选朝代/体裁/字体/范围）· **屏幕取词词典释义** · 简繁与字体切换 · 诗单（像歌单）· 诗词图库 | **桌面小组件** · **输入法** · 成就系统 |
| 创作 / 社区 | UGC 社区：写字 / 语音 / 音乐 / 绘画 / 篆刻 / 原创；话题；精选专辑；文创电商 | 诗词创作空间 |
| AI | **AI 智能体**（与诗人、经典人物跨时空对话） | 按学习行为推送相关资源 |
| 商业化 | 会员 · 书籍 · 文创电商 · 活动 | 广告可关 |

## 二、逐项对照我们（已有 / 差在哪）

| 能力 | 我们的现状 | 结论 |
| --- | --- | --- |
| 多字段内容（译文/赏析/背景/注释） | 有，且**如实标注可信度** | 我们比他们更诚实（他们不会告诉你哪条是模板文） |
| 拼音 | 有（可开关，按字数收缩字号） | 持平 |
| 全文检索 | 有：标题/作者/正文 + 拼音全拼与首字母 | **差在「高亮」与「按字」**（见建议 1） |
| 分类浏览 | 朝代 / 体裁 / 主题，动态分组 | 他们的「主题维度」更细（节日 / 节气 / 时令 / 花卉 / 用典 / 地理） |
| 学习计划 | 有，且**刚补上每日定量与今日任务** | 与「背诵计划」同一思路，持平 |
| 打卡 / 复习 | 艾宾浩斯曲线 + 热力图 + 连续天数 | **他们普遍没有真正的间隔重复**，这是我们的护城河 |
| 客观题 | 有（补全 / 接下句 / 猜作者，机器判卷） | 与「考一考 / 诗词填空」同向，**我们已追上** |
| 飞花令 | 有（单字令） | 他们有接龙 / 看图猜诗 / 诗词测试，**题型更丰富** |
| 朗读 | 有：整篇 + **逐句跟读与单句循环** | 他们的方言/配乐更强；我们的「跟读」更贴近学诗 |
| 抄写 / 练字 | **没有** | 值得借（见建议 3） |
| 桌面小组件 | **没有** | 值得借，但成本分平台（见建议 4） |
| 一日一赏 | 有「今日推荐」单张卡 | 形态差一层：他们是**可滑动的卡片流** |
| 诗单（歌单式） | 收藏夹 + 计划 | 可借「诗单可分享」这一层 |
| 词典释义 / 屏幕取词 | **没有** | 需要可离线分发的词典数据，条件性做 |
| 成就 | 有 10 项 | 持平 |
| 备份 / 迁移 | 有：全量 JSON 导出与合并恢复 | **他们没有**（账号绑定，数据不出自己服务器） |
| 离线 | **全功能离线**，无网络权限依赖 | 他们以在线为主 |

## 三、值得借的三件事（按性价比排序）

### 建议 1 · 检索「高亮 + 按字/按句」——成本最低、收益最直接

**他们是这么做的**：古文岛把「按字、按句搜索并高亮关键词」当成核心卖点写进了百科词条。
我们已经有全文检索和拼音索引（`DatabaseHelper._pinyinIndex`），差的只是最后一层呈现。

**落地方案**（不需要新依赖、不需要新数据）：

1. `search_page.dart` 的结果项把命中的关键词标朱砂（`Text.rich` + 关键词切分，复用 `ShiciText` 令牌）；
2. 新增「按字」入口：正文任意字可点 → 列出含该字的诗句（与 **P2-7 点字查字** 共用同一份
   「含某字/某词的诗句」查询，正是规划里说「两项一起做更省」的那件事）；
3. DAO 加 `searchVersesContaining(String text, {int limit})`：在 1320 首规模下 `LIKE` 足够快，
   真要更快就在现有拼音索引旁边多建一张「句 → 诗」倒排（内存表即可，不必入库）。

**为什么排第一**：这是他们最「可感知」的体验差，而我们离它只差一层 UI。

### 建议 2 · 一日一赏：把「今日推荐」升级成可滑动卡片流

**他们是这么做的**：一日一赏 + 右滑收藏 + 卡片可换背景，是西窗烛日活的主要抓手；
用户评论里有人专门提到「一日一赏的好句赏析，很适合发朋友圈」。

**落地方案**（我们已有的积木比想象中多）：

- 复用 `poem_card_styles.dart` 的三种列表卡样式 + `poem_share_cards.dart` 的两款分享卡；
- 新增一个横向 `PageView` 的「一日一赏」页：一天一期，卡片可左右翻（今日推荐 → 同主题名句 → 昨日漏读），
  右滑或点收藏直接入库，长按导出长图（走已经抽好的 `CardExporter`）；
- 与刚做完的「今日任务」合并入口：首页今日任务卡 → 「赏一首」；
- 内容全部本地可得（`getDailyPoem` + 分类 + 名句表 `kPoemQuotes`），不需要联网。

**为什么值得做**：它把「打开 App 的理由」从「有任务要完成」变成「有一首诗想看看」——后者更轻松。

### 建议 3 · 抄写 / 练字模式——差异化最强，也最贴合我们的次用户

**他们是这么做的**：西窗烛提供练字模式与几十种书体临摹，定位是「一盏灯，一方印」的静心场景。
我们的「家长带孩子背诗」「学生备考」两类用户，抄一遍比读三遍记得住。

**落地方案**（纯 Flutter，可离线，无需字体授权）：

- 正文切到「抄写」态：`CustomPaint` 做米字格 / 竖排格，半透明诗文做字帖底；
- 手写层用 `Listener` + `Path` 记录笔迹（压感取不到就按速度调粗细），可撤销、可清空；
- 「导出我的抄写」复用 `CardExporter` 存成 PNG；
- 字体只提供我们已有的宋体 + 楷体回退，**不做几十种书体**（那是商业字体授权范畴）。

**为什么排第三**：视觉与交互工作量比前两项大，但它是目前最像「别人有、我们没有」的东西。

### 建议 4（条件性）· 桌面小组件：不是不想做，是三个平台成本不同

- **Android**：需要原生 `AppWidgetProvider` + 定时刷新，工作量中等，且桌面端我们没法验收；
- **Windows**：可以做「无边框置顶小窗」，纯 Dart 可完成，成本最低；
- 若要做，建议只在「设置 → 外观」提供，默认关闭。

## 四、明确不借的（以及理由）

| 不借 | 理由 |
| --- | --- |
| UGC 社区 / 创作 / 话题 / 关注 / 精选专辑 | 与「离线、个人使用」的定位直接冲突；更关键的是**内容安全与审核是合规硬成本**，不是技术问题。 |
| 文创电商 · 会员 · 广告 | 项目定位是自用与分享，不是变现。 |
| AI 智能体（与诗人对话） | 必须联网 + 大模型。更重要的是它与我们的**内容诚信原则**相冲突：我们现在连脚本生成的赏析都要如实标注，若引入生成内容，标注体系与成本都得重做。 |
| 方言朗读 / 古人发音模拟 | 依赖系统 TTS 是否提供该语音包，三端不一致；且「模拟古音」的准确性无法验证，宁可不说。 |
| 词典释义 / 屏幕取词 | 需要可离线分发的词典（如 CC-CEDICT，CC-BY-SA）。**有条件再做**：先做「拼音 + 用例」这个小而可靠的子集，不假装有释义。 |
| 几十种书体 | 商业字体授权问题，不在个人项目范围内。 |
| 看图猜诗 / 诗词大会 / 活动运营 | 需要图库与运营投入；飞花令已是我们的趣味入口，够用。 |

## 五、我们比他们强的地方（别在借鉴里丢掉）

1. **真离线**：无网络请求依赖，飞机上、地铁里、断网都完整可用；他们以在线为主。
2. **数据是自己的**：全量 JSON 导出 + 合并恢复，换机不求人；我们甚至把「用户补写的赏析」也纳入备份。
3. **内容诚信**：分级标注 + 本地补写，这在竞品里没人做 —— 这是我们最应该保持的差异点。
4. **真正的间隔重复**：艾宾浩斯曲线 + 客观题反馈，他们多数只有「每日打卡」。
5. **三端同源**：Windows 桌面端可用且有完整功能（大屏读长词的体验远好于手机）。
6. **无账号、无广告、无内购**：打开即用。

| --- | --- | --- | --- |
| 1 | 检索高亮 + 按字按句查询 | 无新依赖、无新数据 | 与规划里的 P2-7 合并做，一次把「含某字/某词的诗句」索引建好 |
