## 一、要解决的问题 与 目标用户

### 1.1 问题域（按急迫度）

| 编号 | 问题 | 现状证据 |
| --- | --- | --- |
| P-1 | **格律门槛**：读者不懂平仄、押韵，读律诗/词只停在字面，背诵也记不牢 | `lib/` 全库检索 `平仄/韵脚/韵部/格律` **零命中**，完全缺失 |
| P-2 | **听觉场景不完整**：能朗读、能倍速、能连播，但**不能挑音色、不能定时关闭**，睡前使用被"要不要关"打断 | `tts_service.dart` 有 `setRate`；无 `getVoices/setVoice`、无 sleep timer |
| P-3 | **习惯养成脆弱**：连续打卡一旦中断即清零，长期坚持被一次意外毁掉 | `database_helper` 有 `streak` 计算，无「冻结/补签」 |
| P-4 | **记忆效率**：复习只有固定艾宾浩斯；收藏、笔记、名句沉淀后**没有再被利用** | `review_page.dart` 存在；无「回顾队列 / 主动回忆卡」 |
| P-5 | **输出场景缺失**：家长/学生想线下抄写、默写、描红，只能盯着屏幕 | `copy_practice_page.dart` 只能屏幕内书写与导出 PNG，无字帖/默写纸模板 |
| P-6 | **趣味天花板**：飞花令只有单字令，单一 | `flying_flower_page.dart` 仅单字令 |
| P-7 | **深度查证**：诗中的典故、地名、人物无法深挖 | 无结构化词条与超链 |
| P-8 | **版式单一**：正文只有一种衬线字体 | 全库仅 `ShiciFont.serif` |

## 三、各项详述（名称 · 核心作用 · 场景 · 优先级 · 关键步骤 · 预期产出）

### F1 格律助手（平仄·韵脚标注 + 韵部查询）｜P0-1
- **核心作用**：读诗时可切换显示逐字平仄、韵脚与粘对；查某字属何韵部及同韵字。
- **场景**：学生读律诗看"哪里押韵、哪里对仗"；爱好者读词看词牌格律；写句前查韵。
- **关键步骤**
  1. 新增 `assets/data/prosody/`：① 平仄字典（常用字，含多音字两读）② 韵表（平水韵 / 词林正韵）。
  2. 新增 `lib/core/prosody.dart`：复用 `lib/utils/verse_splitter.dart` 切句 → 逐字注平仄 → 按律句/词牌判定格式；**未收录字一律标「未审」并如实提示，不猜**（守内容诚信）。
  3. `poem_detail_page.dart` 增加「格律」开关，正文行下叠标注层；颜色取自 `lib/core/design_tokens.dart`（韵脚用朱砂，平仄用双色，须过 `ShiciContrast` 对比度）。
  4. 新增韵部查询入口（搜索页旁或工具区）：字 → 韵部 → 同韵字列表。
  5. 测试 `test/prosody_test.dart`：律句判定、多音字、未收录字降级、韵表覆盖抽查。
- **预期产出**：可切换的格律标注层 + 韵部查询页 + 平仄/韵表数据 + 全绿测试。

### F2 听诗增强（多音色 + 睡眠定时）｜P0-2
- **核心作用**：朗读可选音色；支持"播完当前 / 15·30·60 分"定时，到点渐弱停止。
- **场景**：睡前躺着听，不必起来关；换音色听长词不腻。
- **关键步骤**
  1. `lib/core/tts_service.dart`：新增音色枚举 `getVoices()` 与 `selectVoice()`（**系统无多音色时如实降级为默认音色**，不假装）；新增 `sleepTimer(Duration)` 到点触发渐弱停止。
  2. `poem_detail_page.dart` 播放面板与 `presentation/widgets/tts_queue_bar.dart` 增加音色与定时控件；偏好写入 `shared_preferences`。
  3. 测试：假时钟驱动定时器单测、音色枚举在无音色平台不崩。
- **预期产出**：音色选择 + 睡眠定时（含渐弱）+ 测试。

### F3 打卡韧性（连胜冻结 / 补签卡）｜P0-3
- **核心作用**：连续打卡中断时可「冻结」保住，或用「补签卡」补回。
- **场景**：某天忙没学，用补签卡把连续接回来，不至于前功尽弃。
- **关键步骤**
  1. `lib/data/database/database_helper.dart`：在现有 `streak` 计算（`getStreakDays` 一带）之上引入保护（冻结次数 / 补签卡余额，存表或偏好）；DB 变更走**增量迁移**（沿用 v10 的风格，PRAGMA 先查再加）。
  2. 统计页 / 设置页加 UI；与 `lib/core/achievement_service.dart` 的「坚持类」成就联动。
  3. 测试：断卡补签、冻结消耗、上限、不破坏原有连续天数计算。
- **预期产出**：冻结/补签机制 + 迁移 + 测试。

### F4 阅读字体可选｜P0-4
- **核心作用**：正文可切换 2–3 款**开源**中文字体（如霞鹜文楷、朱雀仿宋，SIL OFL）。
- **场景**：读词换仿宋更雅；竖排读古籍换楷体。
- **关键步骤**
  1. `assets/fonts/` 引入开源字体并在 `pubspec.yaml` 注册为 fontFamily。
  2. 扩展 `ShiciFont` 令牌（`design_tokens.dart`）为可选集合；设置页加「正文字体」。
  3. 应用到详情页正文与 `poem_vertical_body.dart`；**分享卡导出仍须钉死（可复现）**——字体可跟随，但字号/配色不变。
  4. 测试：字体枚举、切换后渲染不溢出（沿用 `ui_font_scale_test.dart` 的溢出拦截思路）。
- **预期产出**：字体选择 + 字体资源（注意授权与体积）+ 测试。

### F5 每日回顾队列 + 主动回忆卡｜P1-5
- **核心作用**：把收藏、名句、笔记自动编入「今日到期 · 昨日遗漏」队列，正面提示→遮蔽作答→自评。
- **场景**：每天打开做 5 分钟回顾，而不是只等艾宾浩斯到点。
- **关键步骤**
  1. 新增 `review_cards` 表（来源标记：收藏/名句/笔记）与 `lib/core/review_queue.dart`（纯函数生成队列，**确定性**、同日可复现）。
  2. 新页 `presentation/pages/review_cards_page.dart`（主动回忆交互）；入口挂首页与复习页。
  3. 测试：队列生成/去重/确定性/空态。
- **预期产出**：回顾队列 + 主动回忆卡页 + 测试。

### F6 复习升级（动态排期 + 困难卡）｜P1-6
- **核心作用**：间隔按掌握度动态伸缩；反复错的自动标「困难」优先排。
- **场景**：记得牢的少打扰，记不牢的多见面。
- **关键步骤**
  1. `database_helper` 复习排期由固定间隔改为 SM-2 变体（EF 可调）；新增困难卡标记（连续错 N 次）。
  2. 统计页补「保留率 / 记忆持久度」可视化（复用 `stats_page.dart` 图表）。
  3. 测试：EF 变化、困难卡阈值，**回归全部现有复习/统计测试**（这是核心逻辑，必须零回归）。
- **预期产出**：动态排期 + 困难卡 + 可视化 + 测试。

### F7 可打印材料（A4 字帖 / 默写纸）｜P1-7
- **核心作用**：按篇目生成可打印的描红字帖或空白默写纸。
- **场景**：家长打印一页描红，孩子照着写。
- **关键步骤**
  1. 复用 `copy_practice_page.dart` 的米字格绘制与 `CardExporter` 导出。
  2. **依赖决策**：若要真 PDF 需引入 `pdf`/`printing` 包；若暂不引依赖，先导出**多页 PNG** 并在文档写明限制（诚实标注）。
  3. 选项：描红 / 空白 / 带拼音 / 竖排。
  4. 测试：生成不崩、页数正确、空内容提示。
- **预期产出**：导出模板 + 文件（PDF 或 PNG）+ 测试。

### F8 趣味扩展（诗词接龙 + 点字成诗）｜P1-8
- **核心作用**：接龙（首尾字/同音/提示）与打乱字拼句，纯本地可玩。
- **场景**：亲子轮流接龙；通勤碎片时间拼句。
- **关键步骤**
  1. 新增 `lib/core/game_solitaire.dart`、`lib/core/game_scramble.dart`（纯函数 + 可注入随机）。
  2. 新页 + 复用飞花段位/成就；题库取自本地 1320 首（无解时如实提示，不出错题）。
  3. 测试：规则正确、无解降级、题目可达性、同种子可复现。
- **预期产出**：两个本地小游戏 + 测试。

### F9–F12（P2，简述）
- **F9 典故·地名·人物词条**：先做高频典故子集 + 详情页专名可点 → 词条卡；与 `content_quality.dart` 标注衔接（**词条来源也要标注**）。
- **F10 出处/底本标注**：数据模型加「底本/出处」字段，走现有内容可信度体系展示。
- **F11 平台集成**：Windows 置顶小窗（纯 Dart，成本最低）→ Android 小组件 → 每日通知；**需真机验收**，故排后。
- **F12 对照读法升级**：把 `poem_parallel_card.dart` 从固定对照改为「原文/译文/注释/赏析/拼音」自由分屏组合。

## 四、批次建议

| **一期** | F1 格律助手 · F2 听诗增强 · F3 打卡韧性 · F4 字体 | 均为**低耦合、可独立验收**，且 F1/F2 是"竞品有、我们缺"的最显性差距 |

## 五、明确不做（沿用调研结论）

联网对战/排行榜/社区 UGC · AI 智能体与 AI 生成内容（与内容诚信冲突）· 会员内购广告 ·
账号与跨设备同步 · 真人朗诵音频与在线曲库（版权）· 方言与古音模拟（不可验证）· 商业书体（授权）·
AR 实景（噱头且需联网）。
